# claude-plugins

Small Claude Code plugins with personality. Built to be fun, made to work.

| Plugin | Type | What it does |
| --- | --- | --- |
| [spinner-moods](plugins/spinner-moods) | mod | Colors and animates the spinner by what Claude is doing (inference, running tools, or something else), with themes, palettes, and little reactions |
| [voiceprint](plugins/voiceprint) | skill | Learns how you write from your own messages and docs, then drafts in your voice |

## Install

At the prompt of a Claude Code session:

```
/plugin install spinner-moods --marketplace tatianajiselle/claude-plugins
/plugin install voiceprint --marketplace tatianajiselle/claude-plugins
```

Or add the marketplace once and browse:

```
/plugin marketplace add tatianajiselle/claude-plugins
/plugin install voiceprint@tatianajiselle
```
